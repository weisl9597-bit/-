# 设计宝运营预警工作台 MVP 原型设计

## 目标

生成一套可直接查看、可点击演示的前端原型，用于验证信息架构与核心使用路径，不连接真实后台，不实现数据上传、权限、规则配置或任务闭环。

## 产品定位

第一版围绕一个问题展开：城市负责人每天打开系统后，能否快速发现异常商家和项目，并进一步定位原因。

核心路径为：

`首页预警 → 指标分析 → 商家定位 → 项目事实`

## 交付形态

- 桌面端响应式单页 Web 原型。
- 使用本地模拟数据，刷新后回到默认视图。
- 无需安装服务即可查看；如工程脚手架需要本地启动，则提供清晰启动方式。
- 视觉风格偏运营数据产品：克制、清晰、重点状态醒目，不追求复杂装饰。

## 全局结构

左侧主导航包含：

1. 首页
2. 指标中心
3. 商家中心
4. 项目中心

顶部区域包含当前组织、数据更新时间、日期范围和用户入口。所有页面共享一致的筛选、状态色与详情进入方式。

## 首页：运营预警工作台

首页回答“今天哪里需要关注”。

### 页面内容

- 今日总览：商家总数、A/B/C 商家数、应辅导商家数、辅导率、已辅导未改善数、异常项目数。
- 今日关注：辅导执行异常、商家改善异常、项目异常三类预警卡片。
- 商家结构：A/B/C/已淘汰分布及关键分类变化。
- 重点城市或商家排行，用于形成明确的下一步入口。

### 交互

- 点击预警卡片进入对应商家或项目列表，并自动带入筛选条件。
- 点击商家分类或变化进入商家中心。
- 点击异常项目数量进入项目中心。

## 指标中心

指标中心回答“哪个指标出了问题，问题在哪里”。

### 页面内容

- 指标组与指标选择：分派开口、SOP 执行、群聊质量、深度连接、结果转化、签约。
- 时间选择：今日、本周、上周、本月、自定义；周口径固定为周日至周六。
- 核心指标摘要、趋势图、组织表现对比和异常贡献列表。
- 下钻路径提示：指标 → 大区 → 城市 → 商家 → 项目。

### 交互

- 切换指标和时间范围后更新页面模拟数据与文案。
- 点击组织或商家行完成逐级下钻。
- 点击项目行进入项目详情。
- 提供面包屑返回上一级。

## 商家中心

商家中心回答“哪些商家需要经营动作”。

### 页面内容

- 分类、城市、辅导状态、改善状态等筛选。
- 商家列表展示分类、分类变化、SOP 达标率、环比、是否辅导、是否改善、异常项目数、本月签约、最后分派时间。
- 商家详情采用侧滑面板或页面内详情，展示进入 B/C 的原因、辅导与改善状态、指标趋势和项目明细。

### 交互

- 搜索与条件筛选即时更新列表。
- 点击商家打开详情。
- 点击详情内异常项目进入项目详情。

## 项目中心

项目中心回答“具体哪些项目需要处理”。

### 页面内容

- 默认异常项目优先。
- 支持组织、时间、项目状态、异常状态、商家分类筛选。
- 列表展示项目 ID、大区、城市、商家、商家分类、分派时间、项目状态、SOP 是否达标、是否需辅导、是否辅导、是否改善。
- 项目详情展示基础信息、运营状态、SOP 执行明细、相关指标和所属商家近 14 天情况。

### 交互

- 点击项目打开详情。
- 点击所属商家进入商家详情。
- 首页和其他页面带入的筛选条件可见且可清除。

## 示例数据与状态规则

- 使用一组贯穿四页的中国大区、城市、商家和项目模拟数据，确保同一对象在不同页面的数据一致。
- 状态色统一：正常/改善为绿色，关注/待辅导为橙色，异常/未改善为红色，中性信息为蓝灰色。
- A 类为稳定，B 类为预警，C 类为汰换观察，已淘汰使用中性灰。
- 空值不隐藏，统一显示为“待填写”或“—”，避免用户误判为否。

## 体验原则

- 首页优先呈现行动信息，而非堆叠图表。
- 每个异常都应有明确入口，最多三次点击到达具体项目。
- 页面默认状态即可讲清故事，不要求评审者先配置筛选。
- 表格信息密度适中，重要状态使用标签，不用大面积高饱和色。
- 详情不离开当前分析上下文，关闭后保留原筛选和滚动位置。

## 非目标

本次不包含：真实 Excel 上传、数据库、登录与权限、规则中心配置、任务派发与跟进、消息通知、导出报表、移动端专项适配、生产部署。

## 验收标准

1. 四个主导航页面均可访问，当前导航状态明确。
2. 首页至少三个预警入口可以跳转并带入对应筛选。
3. 指标中心可以切换指标、时间并演示至少三级下钻。
4. 商家中心可以筛选、搜索并查看商家详情。
5. 项目中心可以筛选并查看项目详情，且能返回所属商家。
6. 同一商家和项目在不同页面中的示例数据保持一致。
7. 常见桌面宽度下无横向页面溢出，关键内容层级清楚。
8. 提供可复现的本地查看方法，并完成基础交互与视觉检查。
